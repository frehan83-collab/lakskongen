## 🔧 Integration Workflow

### Step 1: Capture Screenshots
1. Launch Godot + Lakskongen project
2. Enter Photo Mode (`P` key)
3. Capture 6-10 candidate shots per capsule type
4. Save to `salmon-sim/screenshots/steam_store/raw/`

### Step 2: Select Best Shots
1. Review all candidates
2. Pick best for each capsule slot
3. Check composition, lighting, clarity
4. Verify no UI bugs or placeholders

### Step 3: Generate Final Capsules
1. Place selected screenshots in `screenshots/steam_store/selected/`
2. Edit `generate_capsules.py` to load screenshots:
   ```python
   bg = Image.open("selected/main_capsule_source.png")
   bg = bg.resize((width, height), Image.Resampling.LANCZOS)
   ```
3. Run `python generate_capsules.py`
4. Review output in `capsules/`

### Step 4: Quality Review
1. Check `preview_all_capsules.png`
2. Verify dimensions and file sizes
3. Test on dark Steam background
4. Get second opinion

### Step 5: Upload to Steam
1. Log in to Steamworks Partner
2. Navigate to Store Page → Graphical Assets
3. Upload each capsule to correct slot
4. Preview on Steam store page
5. Submit for review
