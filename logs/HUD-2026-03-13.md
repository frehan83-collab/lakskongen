## HUD.gd

### What it shows
| Widget | Data source | Color logic |
|--------|-------------|-------------|
| Day counter | `SimBridge.current_day` | neutral |
| Season icon + name | `SimBridge._season_name()` | ❄/🌱/☀/🍂 |
| Balance (NOK) | `SimBridge.balance` + `format_nok()` | green ≥ 500 kNOK, yellow ≥ 0, red < 0 |
| Fish count | `SimBridge.fish_count` + `format_fish()` | green > 0, yellow = 0 |
| Temperature | `SimBridge.temperature_c` | green 8–16°C, yellow 4–8/16–18°C, red outside |
| Market price | `SimBridge.market_price_nok` | green ≥ 75 NOK/kg, yellow ≥ 60, red < 60 |
| Speed buttons | `SimBridge.set_time_speed()` | 1×, 2×, 5× + pause toggle |

### Key design decisions
- All data sourced from `SimBridge` (no direct `GameBridge` C# calls).
- Speed buttons are **1× / 2× / 5×** (previously 7× / 30×) for smoother
  player pacing during early gameplay.
- `signal speed_changed(speed, paused)` lets other nodes (Dashboard,
  tutorial) react to time changes.
- Spacebar bound to pause/resume via `_input`.

## NotificationCenter.gd

### Behaviour
- **Max 20 entries**, newest on top; older entries trimmed automatically.
- **Auto-opens** when severity == `"critical"` (disease outbreaks, game-over
  risk alerts).
- **Toggle** via `N` key (`toggle_notifications` input action) or programmatic
  call to `toggle()` / `show_panel()` / `hide_panel()`.
- Clicking any entry **expands** its description inline; clicking again
  collapses it.
- Entries are ingested from two sources:
  1. `SimBridge.alert_raised` signal (real-time threshold alerts).
  2. `SimBridge.recent_events` array on each `state_updated` tick
     (deduplicated by day + title).

### Severity colours
| Severity | Accent colour |
|----------|--------------|
| `info` | Light blue |
| `warning` | Yellow |
| `critical` | Red |

### Slide animation
Expects `AnimationPlayer` child with `"slide_in"` and `"slide_out"` clips.
Falls back gracefully if the animations are absent.

## ToastNotification.gd

### Behaviour
- Registered as **CanvasLayer** (layer 10) so it renders above all game UI.
- Toasts **queue** — multiple events never overlap; each is shown in order.
- Each toast **slides in from the top-right** via a Tween (Cubic/EaseOut),
  remains visible for the configured duration (default 4 s), then slides out.
- Player can **dismiss early** with the `✕` button.
- Auto-listens to `SimBridge.alert_raised`; can also be triggered manually:

```gdscript
var toast: Node = get_node("/root/ToastNotification")
toast.push("🐟 Høsting fullført", "2 400 laks — 18 500 kg", "info", 4.0)
toast.push("🦠 Sykdomsutbrudd!", "ILA påvist i Sone 3", "critical")
```

### Signals exposed
```
toast_shown(title, severity)
toast_dismissed(title)
```

## Integration notes

1. **Autoloads to register** in `project.godot`:
   ```
   SimBridge        = "res://scripts/SimBridge.gd"
   ToastNotification = "res://scripts/ui/ToastNotification.gd"
   ```
2. **Input actions** to add in `Project → Input Map`:
   - `toggle_notifications` (suggested: N key)
3. **Scene setup**: HUD.tscn and NotificationCenter.tscn need matching node
   trees as documented in each script's header comment.
4. The `speed_1x` / `speed_2x` / `speed_5x` button names in HUD.tscn must
   match the `@onready` paths.
