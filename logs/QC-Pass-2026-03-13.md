## Bug Details & Fixes

### BUG-01 — `ProcessingManager.UtilizationMultiplier`: Discontinuity at 0.6 (Logic Error)
**File:** `Processing/ProcessingManager.cs:64`
**Severity:** High — incorrect P&L values for all processing plants at 30–60% utilization

**Root cause:** The second piecewise segment used `0.9m * (ratio - 0.3m) / 0.3m + 0.6m`.
At `ratio = 0.6−ε` this evaluates to `0.9 × 1 + 0.6 = 1.5`, but the third segment starts at 0.9, creating a jump of −0.6 (efficiency cliff) that could produce nonsense EBITDA swings in the dashboard.

**Fix:**
```csharp
// Before
if (utilizationRatio < 0.6m) return 0.9m * (utilizationRatio - 0.3m) / 0.3m + 0.6m;
// After
if (utilizationRatio < 0.6m) return 0.6m + 0.3m * (utilizationRatio - 0.3m) / 0.3m; // ramp 0.6→0.9
```
The fixed formula is a linear ramp from 0.6 (at ratio=0.3) to 0.9 (at ratio=0.6), matching the existing third-segment boundary exactly.

### BUG-02 — `DistressedAsset.DiscountPercentage`: DivideByZeroException (Runtime Crash)
**File:** `Events/CrisisCapitalismSystem.cs:58`
**Severity:** High — throws `DivideByZeroException` whenever `OriginalValueNOK == 0`

**Fix:**
```csharp
// Before
public float DiscountPercentage => (float)((OriginalValueNOK - DiscountedPriceNOK) / OriginalValueNOK);
// After
public float DiscountPercentage => OriginalValueNOK == 0m ? 0f : (float)((OriginalValueNOK - DiscountedPriceNOK) / OriginalValueNOK);
```

### BUG-03 — `VerticalIntegrationSystem.IsUnlocked`: Unsafe `Enum.Parse` (Runtime Crash)
**File:** `Expansion/VerticalIntegrationSystem.cs:95`
**Severity:** High — `condition.Value.ToString()` throws `NullReferenceException` if value is null; `Enum.Parse` throws `ArgumentException` for unrecognised strings

**Fix:** Replaced with null-safe `Enum.TryParse<IntegrationTier>` and graceful skip on parse failure:
```csharp
// Before
var requiredTier = (IntegrationTier)Enum.Parse(typeof(IntegrationTier), condition.Value.ToString());
// After
var tierStr = condition.Value?.ToString() ?? string.Empty;
if (!Enum.TryParse<IntegrationTier>(tierStr, out var requiredTier))
    break; // unrecognised tier value in data — skip condition
```

### BUG-04 — `Wellboat.TripCost`: DivideByZeroException (Runtime Crash)
**File:** `Logistics/Wellboat.cs:21`
**Severity:** Medium — `1.5 / PortAccessScore` throws when `PortAccessScore == 0`; constructor default is 1.0 but callers can pass 0

**Fix:**
```csharp
// Before
var baseMultiplier = 1.5 / PortAccessScore;
// After
var baseMultiplier = 1.5 / System.Math.Max(0.001, PortAccessScore); // guard against zero
```
