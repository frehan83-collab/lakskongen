**Commit:** feat: Weather-reactive audio system with crossfade and ambient layers

## What was built

### 1. `src/LakskongenSim/Core/AudioManager.cs` (pure C#, no Godot)
Simulation-layer audio state machine. Zero Godot dependencies.

- Tracks: weather state (calm/wind/storm), season (spring/summer/autumn/winter), location context (SeaSite/Harbor/ProcessingPlant), active alert key, master volume.
- `Update(int day)` — called once per simulated day from `AdvanceOneDay()`. Derives season from day-of-year and reads `WeatherSystem.CurrentState`.
- `GetAmbienceProfile()` → returns `AmbienceProfile { BaseTrack, WeatherLayer, AlertLayer, Volume }`.
  - **BaseTrack**: `calm_sea | wind | storm | harbor | processing_plant`
  - **WeatherLayer**: `"" | wind | storm` (additive overlay)
  - **AlertLayer**: `"" | disease_outbreak | market_crash | achievement | harvest | lice_warning`
- `GetSeasonalTrack()` → `spring_theme | summer_theme | autumn_theme | winter_theme | main_theme`.
- `TriggerAlert(key)` / `ClearAlert()` — queue and consume one-shot alert sounds.

### 2. `SimulationEngine.cs` — integration
- Added `public AudioManager Audio { get; private set; }` property.
- `Initialize()`: creates `Audio = new AudioManager(Weather)` after Weather is initialised.
- `AdvanceOneDay()`: calls `Audio?.Update(State.Day)` right after `Weather.AdvanceDays(1)`.
- `HandleStorytellerEvent()`: triggers `disease_outbreak` on `EventCategory.Disease`, `market_crash` on negative-balance market events.
- `OnSustainabilityScoreChanged()`: triggers `achievement` when Sustainability Leader threshold reached.

### 3. `godot/scripts/autoload/GameBridge.cs` — audio bridge properties
New signal: `AudioAlertTriggered(alertKey)` — emitted in `OnSimulationTick()` when `Audio.ActiveAlert` is non-empty; alert is cleared immediately after emit.

New computed properties (all read-only, GDScript-friendly):
| Property | Type | Description |
|---|---|---|
| `AudioBaseTrack` | `string` | Base ambient track key |
| `AudioWeatherLayer` | `string` | Weather overlay key |
| `AudioAlertLayer` | `string` | Pending alert key |
| `AudioVolume` | `float` | Master volume 0–1 |
| `AudioSeasonalTrack` | `string` | BGM track name for current season |
| `CurrentWeatherState` | `string` | calm / wind / storm |

### 4. `godot/scripts/SimBridge.gd` — GDScript-friendly audio state
New signal: `audio_alert_triggered(alert_key: String)`.

New vars refreshed every tick:
- `audio_base_track`, `audio_weather_layer`, `audio_alert_layer`, `audio_volume`
- `audio_seasonal_track`, `audio_weather_state`

Lice warning: `_check_alerts()` now emits `audio_alert_triggered("lice_warning")` when sea lice crosses the critical threshold (>5.0).

### 5. `godot/scripts/MusicLibrary.gd`
Static catalogue of all audio resource paths. Dictionaries:
- `MUSIC_TRACKS` — seasonal BGM + menu/harbor/storm variants
- `AMBIENT_BASE` — 6 base ambient loops (calm_sea, storm, wind, rain, harbor, processing_plant)
- `AMBIENT_WEATHER` — 3 additive weather overlays (wind, rain, storm)
- `ALERT_SFX` — 5 alert one-shots
- `UI_SFX` — 6 UI sounds

Static helper methods: `music(key)`, `ambient_base(key)`, `ambient_weather(key)`, `alert_sfx(key)`, `ui_sfx(key)`.

### 6. `godot/scripts/AudioController.gd`
Godot-layer audio controller (register as autoload after SimBridge).

**Three independent layers:**
- **BGM** — two `AudioStreamPlayer` nodes (active + pending). 1.5 s crossfade driven by `_process()`. Switches on `audio_seasonal_track` change.
- **Ambient base** — single player, hard-switches to new stream when `audio_base_track` changes.
- **Ambient weather overlay** — single player, fades in/out (2 s tween) when `audio_weather_layer` changes. Runs at 60% of ambient volume so base always audible.
- **SFX pool** — 8 `AudioStreamPlayer` nodes. One-shot plays from `play_sfx(path)`.

**Signal wiring:**
- `SimBridge.state_updated` → `_on_state_updated()` → updates BGM + ambient each tick.
- `SimBridge.audio_alert_triggered` → `_on_alert_triggered()` → plays one-shot from pool.

**Public API:**
- `set_music_volume(float)`, `set_ambient_volume(float)`, `set_sfx_volume(float)`, `set_master_volume(float)`, `set_music_muted(bool)`
- `play_sfx(path, volume_db, pitch)`, `play_ui(sound_key)`

## Architecture diagram

```
SimulationEngine.AdvanceOneDay()
  └─ Weather.AdvanceDays(1)
  └─ Audio.Update(day)          ← AudioManager.cs (pure C#)
       ↓ reads WeatherState + season

GameBridge.OnSimulationTick()
  └─ emits AudioAlertTriggered(key)   ← if alert queued
  └─ exposes AudioBaseTrack, AudioSeasonalTrack, …

SimBridge.gd
  └─ mirrors audio_* vars from GameBridge
  └─ re-emits audio_alert_triggered signal

AudioController.gd
  └─ subscribes state_updated  → crossfade BGM, update ambient layers
  └─ subscribes audio_alert_triggered → play one-shot SFX from pool
```
