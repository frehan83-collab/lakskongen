## Summary

Implemented a complete Save/Load system for `LakskongenSim` covering JSON serialization of the full `GameState` graph, backup file rotation, and round-trip test coverage.

## 1. Serialization Fixes in Domain Classes

### `Environment/WaterChemistry.cs`
- Changed all state-variable properties (`AmmoniaNH4`, `NitriteNO2`, `NitrateNO3`, `PhosphorusPO4`, `OxygenO2`, `pH`) from `private set` → `set` so System.Text.Json can deserialize them.
- Added `public double Temperature { get => _temperature; set => _temperature = value; }` to expose the private `_temperature` field through the JSON graph.
- Added parameterless `public WaterChemistry()` constructor (delegates to `this(10.0)`) required by the deserializer.

### `Environment/Zone.cs`
- Changed `WaterChemistry { get; private set; }` → `{ get; set; }`.
- Added parameterless `public Zone()` constructor (delegates to `this("")`) for deserialization.
- `Id { get; init; }` is supported natively by System.Text.Json in .NET 8.

### `Biology/FishPopulation.cs`
- Added `[JsonConstructor] public FishPopulation()` parameterless constructor. The `GrowthModel` and `MortalityModel` fields are **behavioural** (not state), so they are not serialized; the simulation engine must re-inject them after a load.
- Changed `private readonly GrowthModel _growth` / `_mortality` to non-readonly nullable (`= null!`) to allow the parameterless constructor.
- Changed `Cohorts { get; }` → `{ get; set; }` so the deserializer can replace the list.
- Added public `GrowthPenalty { get => _growthPenalty; set => _growthPenalty = value; }` property so the penalty survives round-trips; `GetGrowthPenalty()` now delegates to this property.

### `Farm/SeaSite.cs`
- Added `[JsonIgnore]` on computed properties `CurrentBiomassTonnes` and `IsOverMAB` (derived from other fields — no need to persist).
- Changed `EscapesThisYear { get; private set; }` and `CurrentStockingDensity { get; private set; }` → `{ get; set; }`.
- Changed `Pens { get; }` → `{ get; set; }` for list deserialization.
- Added parameterless `public SeaSite()` constructor (`Id = ""`).
- Added `using System.Text.Json.Serialization;`.

> **Note:** C# events (`OnStocked`, `OnEscapeEvent`, `OnMABExceeded`, `OnPopulationChanged`) are not serialized by System.Text.Json by default — no attribute required.

## 2. Core/SaveLoadManager.cs (New File)

**Location:** `src/LakskongenSim/Core/SaveLoadManager.cs`
**Namespace:** `LakskongenSim.Core`
**Dependencies:** `System.IO`, `System.Text.Json` (already in project)

### API

| Method | Description |
|--------|-------------|
| `SaveGame(GameState, string saveName = "save")` | Rotates backups, then writes `<saveName>.json` |
| `LoadGame(string saveName = "save")` | Deserializes from `<saveName>.json`; throws if missing |
| `TryLoadWithFallback(string saveName = "save")` | Tries primary, then `.bak1`→`.bak3`; returns `null` on failure |

### Backup Rotation

On each `SaveGame` call, before overwriting:
```
.bak2 → .bak3  (oldest backup evicted)
.bak1 → .bak2
primary → .bak1
```
Maximum 3 backup generations are retained per save slot.

### Serializer Options

```csharp
new JsonSerializerOptions
{
    WriteIndented = true,
    Converters = { new JsonStringEnumConverter() }   // enums as strings (readable + stable)
}
```

## 4. Architectural Notes

- **No Godot dependency.** `SaveLoadManager` lives in the pure C# `LakskongenSim` library. The existing `godot/scripts/autoload/SaveLoadManager.cs` wraps this for Godot file paths and signal emission.
- **Post-load injection pattern.** `FishPopulation._growth` and `._mortality` are not serialized. The `SimulationEngine` (or a loading helper) must call `new FishPopulation(growthModel, mortalityModel)` equivalents on deserialized populations before advancing simulation days. A future `GameLoader` helper could handle this automatically.
- **Enum stability.** Using `JsonStringEnumConverter` means save files are stable against enum reordering — a common bug source in long-running games.
