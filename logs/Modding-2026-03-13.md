## ModLoader.cs

**Namespace:** `LakskongenSim.Core`

### Key Classes

#### `ModManifest`
Deserialized from `manifest.json` at the root of each mod folder.

| Field | Type | Description |
|-------|------|-------------|
| `Id` | string | Unique mod identifier |
| `Name` | string | Display name |
| `Author` | string | Mod creator |
| `Version` | string | Semver string |
| `Description` | string | Human-readable summary |
| `Files` | `List<string>` | Relative paths to JSON data files |
| `Dependencies` | `List<string>` | Mod IDs that must load before this one |
| `Enabled` | bool | Runtime toggle (not persisted to JSON) |

#### Mod data payloads (JSON-serializable)
- **`ModEventDefinition`** — mirrors `EventDefinition` but with no delegate fields. Supports numeric effects dictionary (`balance_change`, `lice_change`, etc.) and simple conditions (`condition_min_balance`, `condition_min_day`).
- **`ModResearchNode`** — adds new research nodes to the tech tree with full branch/tier/cost/effects support.
- **`ModFishSpecies`** — registers new fish species with growth, temperature, FCR, and price multipliers.
- **`ModScenario`** — defines custom campaign scenarios with starting capital, region, difficulty, and win condition.

#### `LoadedMod`
Container for everything parsed from a single mod folder.

#### `ModLoader`
Main loader class.

**Key methods:**
- `DiscoverAndLoad()` — scans `mods/` directory, resolves dependency order via topological sort, loads all enabled mods.
- `BuildEventDefinitions()` — converts `ModEventDefinition` objects into runtime `EventDefinition` instances with closure-based conditions and effects.
- `GetAllResearchNodes()` / `GetAllFishSpecies()` / `GetAllScenarios()` — aggregate content from all enabled mods.
- `SetModEnabled(id, bool)` — runtime toggle; takes effect on next `DiscoverAndLoad()`.

**File naming convention for JSON data files:**

| Filename prefix | Deserializes as |
|-----------------|----------------|
| `events_*.json` | `List<ModEventDefinition>` |
| `research_*.json` | `List<ModResearchNode>` |
| `fish_*.json` | `List<ModFishSpecies>` |
| `scenarios_*.json` | `List<ModScenario>` |

## DataExporter.cs

**Namespace:** `LakskongenSim.Core`

Uses Norwegian locale (`nb-NO`) for number formatting:
- Decimal separator: `,`
- Thousands separator: ` ` (space)
- CSV field separator: `;` (semicolon, to avoid decimal comma collision)

### Export Methods

| Method | Output | Columns |
|--------|--------|---------|
| `ExportDailySnapshots(path)` | One row per simulated day | Dag, Fiskeantall, Totalbiomasse_kg, Gjennomsnittsvekt_kg, Temperatur_C, Markedspris_NOK, Saldo_NOK, FCR, Lus_per_fisk, Baerekraftsscore, Doedsrate |
| `ExportFinancialReport(path)` | One row per 30-day period | Periode, FraDag, TilDag, Saldo_start_NOK, Saldo_slutt_NOK, Endring_NOK, Gj_markedspris_NOK, Gj_biomasse_kg, Gj_baerekraftsscore, Gj_FCR |
| `ExportPopulationData(path)` | One row per simulated day | Dag, Fiskeantall, Totalbiomasse_kg, Gjennomsnittsvekt_kg, Temperatur_C, Lus_per_fisk, Doedsrate, Baerekraftsscore, FCR |
| `ExportEventHistory(path)` | One row per event | Dag, Hendelses-ID, Navn, Kategori, Beskrivelse, Saldoendring_NOK |
| `ExportAll(directory)` | Four files, auto-named with day | Returns `ExportSummary` with row counts and paths |

### `ExportSummary`
Returned by `ExportAll()`; contains paths and row counts for all four files and a `TotalRowsExported` property.

## ModManagerPanel.gd

**Extends:** `Control`

**Signals:** `mods_changed()`, `panel_close_requested`

### Features
- **Mod list** — scrollable rows showing name, version, author, and status badge (Aktiv / Deaktivert / ⚠ Feil).
- **Enable/disable toggle** — per-row `CheckBox`; disabling greys out the mod name.
- **Load order drag** — click the ⠿ drag handle and drag rows to reorder mods.
- **Detail pane** — right-side panel shows name, author, version, description, content stats (event count, research node count, species count, scenario count), and any load errors.
- **Toolbar buttons:**
  - *Åpne modmappe* — opens `mods/` folder in OS file manager.
  - *Last inn på nytt* — calls `GameBridge.ReloadMods()` then refreshes the list.
  - *Bruk endringer* — pushes `{id, enabled}` array to `GameBridge.ApplyModSettings()` and emits `mods_changed`.
- **GameBridge integration** — calls `GetModList()` to populate; falls back to placeholder if bridge unavailable.

## DataExportPanel.gd

**Extends:** `Control`

**Signals:** `export_completed(path, rows)`, `panel_close_requested`

### Features
- **Four export cards** — one per data type, each showing icon, title, subtitle, description, and an *Eksporter CSV* button.
- **Export all** — single button exports all four datasets at once with progress bar.
- **Path selector** — `LineEdit` + *Bla gjennom* button opens a native OS `FileDialog` for directory selection. Defaults to `~/Documents/LakskongenSim/Eksport`.
- **Progress bar** — shown during export, fills to 100% then hides.
- **Export log** — `RichTextLabel` with color-coded entries: green for success, red for errors, grey for info.
- **Status label** — live text in title bar (Klar / Eksporterer... / Ferdig / Feil).
- **GameBridge integration** — calls `GameBridge.ExportDailySnapshots(path)`, `ExportFinancialReport(path)`, `ExportPopulationData(path)`, `ExportEventHistory(path)`.

## GameBridge Integration Points

The following methods must be exposed on `GameBridge` for full UI integration:

| Method | Returns | Purpose |
|--------|---------|---------|
| `GetModList()` | `Array[Dictionary]` | Mod list for ModManagerPanel |
| `ReloadMods()` | void | Re-scan mods/ directory |
| `ApplyModSettings(settings: Array)` | void | Push enabled/order changes |
| `ExportDailySnapshots(path: String)` | int | Rows exported |
| `ExportFinancialReport(path: String)` | int | Rows exported |
| `ExportPopulationData(path: String)` | int | Rows exported |
| `ExportEventHistory(path: String)` | int | Rows exported |
| `GetCurrentDay()` | int | For auto-naming export files |

## Integration Notes

- `ModLoader` is standalone; instantiate with the path to `mods/` and call `DiscoverAndLoad()`.
- Call `ModLoader.BuildEventDefinitions()` and register the returned `EventDefinition` list with `Storyteller` before the first `AdvanceOneDay()`.
- `DataExporter` takes a `GameState` reference; construct after the simulation is running.
- Both GDScript panels gracefully degrade when `GameBridge` is not present (placeholder data / log error message).
- CSV files are UTF-8 encoded with BOM — Excel on Norwegian Windows will open them correctly without import wizard.
