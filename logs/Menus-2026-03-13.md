**Date:** 2026-03-13
**Author:** Aksel Berg (Tech Lead)

## Summary

Implemented the full menu and settings layer for Lakskongen. Four GDScript files were created or fully rewritten in `godot/scripts/ui/`, all following the established codebase patterns (SimBridge integration, procedural styling, tween animations, Godot 4 signal syntax).

---

## Files Delivered

### 1. `SettingsMenu.gd` (rewrite of stub)

Full tabbed settings panel — previously a stub with empty handlers.

**Tabs:**
- **Lyd (Audio)** — Master, Music, Ambient, SFX volume sliders (0–100%). Live preview: changes are applied to `AudioServer` buses immediately on drag. Falls back to direct `AudioServer` calls if `AudioManager` autoload is unavailable.
- **Grafikk (Graphics)** — Resolution `OptionButton` (5 presets: 720p→4K), Fullscreen `CheckBox` (calls `DisplayServer.window_set_mode`), VSync `CheckBox` (calls `DisplayServer.window_set_vsync_mode`).
- **Spill (Gameplay)** — Autosave interval `OptionButton` (Off / 2 / 5 / 10 / 30 min), Tutorial enabled `CheckBox`, Notifications enabled `CheckBox`, Default sim speed `HSlider`.

**Persistence:**
- Settings saved to `user://settings.json` on Apply or Close (if dirty).
- Loaded with `_load_settings()` at `_ready()`; missing keys filled from `DEFAULT_SETTINGS`.
- `load_and_apply()` public method called by `MainMenu` on startup to restore the last session.
- Reset button restores all values to `DEFAULT_SETTINGS`.

**Signals emitted:** `settings_applied`, `close_requested`.

### 2. `MainMenu.gd` (rewrite of stub)

Title screen — previously a stub with `print()` placeholders.

**Buttons:**
- **Nytt Spill** — calls `GameBridge.start_new_game()` then cross-fades to `res://scenes/Main.tscn`.
- **Last inn spill** — opens `SaveLoadMenu` sibling node.
- **Innstillinger** — opens `SettingsMenu` sibling node.
- **Kreditter** — opens `CreditsScreen` sibling node.
- **Avslutt** — fades out and calls `get_tree().quit()`.

**Salmon-themed background (procedural):**
- Two layered `ColorRect` nodes provide a deep-ocean gradient (`#0A1938` / `#0F3366` at 60% alpha).
- A looping tween pulses a white `Shimmer` rect at 0→6%→0 opacity (6 s cycle) to simulate light caustics.
- 8 drifting fish emoji (`🐟 🐠 🐡 🦈`) are spawned in `SalmonLayer` at random positions with varying opacity (25–55%), sizes (24–52 px), and left-drift velocities, wrapping horizontally.

**Startup sequence:** `settings_menu.load_and_apply()` is called so saved audio/graphics settings take effect immediately.

**Signals handled:** `close_requested` from all three submenus re-enables main buttons.

### 3. `PauseMenu.gd` (rewrite of stub)

In-game pause overlay — stub had minimal signal-only approach.

**Buttons:**
- **Fortsett** — emits `resume_requested`, calls `hide_menu()` (unpauses tree).
- **Lagre spill** — calls `SaveLoadManager.save_game("quicksave")`, shows inline "Lagrer…" / "Lagret ✓" feedback.
- **Last inn spill** — opens `SaveLoadMenu` sibling.
- **Innstillinger** — emits `settings_requested`, opens `SettingsMenu` sibling.
- **Tilbake til hovedmeny** — unpauses, fades out, changes scene to `MainMenu.tscn`.
- **Avslutt** — unpauses, fades out, quits.

**Pause mechanics:**
- `process_mode = PROCESS_MODE_ALWAYS` so the overlay responds to input while `get_tree().paused = true`.
- Also calls `GameBridge.set_paused(bool)` if the method exists, ensuring the C# sim tick halts.
- Escape key closes the menu via `_unhandled_input`.

**Animations:** Panel pops in with `TRANS_BACK / EASE_OUT` scale bounce (0.88→1.0); fades out smoothly on close.

**Backwards-compatible signals kept:** `resume_requested`, `settings_requested`, `save_requested`, `quit_to_menu_requested`.

## Architecture Notes

- All four scripts follow the **SimBridge pattern**: `get_node_or_null("/root/SimBridge")` with graceful degradation.
- Audio integration goes through `AudioManager.set_bus_volume(bus, linear)` with a direct `AudioServer` fallback.
- Procedural UI construction (no hard `.tscn` dependency for styling) ensures visual consistency with `NotificationCenter` and `AnalyticsPanel` patterns.
- Settings file at `user://settings.json` uses the same `FileAccess` + `JSON.parse_string` pattern used elsewhere in the codebase.
- `PauseMenu` correctly sets `process_mode = PROCESS_MODE_ALWAYS` so it remains interactive while the scene tree is paused.
