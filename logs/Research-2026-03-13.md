## Architecture

### ResearchSystem.cs
- `ResearchNode`: immutable definition (id, name, description, branch, tier, cost, days, prerequisites, effects) + mutable `Unlocked` state
- `ResearchBranch` enum: Biology, Technology, Sustainability, Processing, Expansion
- `ResearchSystem`: holds all 25 nodes in a dictionary keyed by ID
- `StartResearch(nodeId)`: validates prereqs, sets active research (caller handles balance deduction)
- `AdvanceDay()`: increments `ResearchProgress`, fires `OnResearchCompleted` when `progress >= researchDays`
- `GetTotalEffect(key)`: sums effect values across all unlocked nodes for a given modifier key
- `ForceUnlock(id)` / `RestoreProgress(id, progress)`: save/load support

### SimulationEngine integration
- `Research` property exposed as public field
- Phase 10 in `AdvanceOneDay()` calls `Research.AdvanceDay()`
- `SyncResearchToState()` helper keeps `GameState` serialisation fields up to date every tick
- `OnResearchCompleted` event forwarded to UI and audio system

### GameBridge API (GDScript-visible)
```
GetResearchNodes()       → Array[Dictionary]  (all 25 nodes with status)
StartResearch(nodeId)    → bool               (balance check + cost deduction)
CancelResearch()         → void
ActiveResearchId         → String
ResearchProgress         → int (days)
ResearchDaysRemaining    → int
IsResearchUnlocked(id)   → bool
GetResearchEffect(key)   → double
ResearchCompleted signal  (nodeId, nodeName)
```

### TechTreePanel.gd
- 5 branch columns × 5 tier rows, fully procedural layout
- `_LineCanvas` inner class: draws elbow connectors with arrow heads; colour-coded by connection state
- Node status colours: 🔒 locked (dark grey), 🔬 available (ocean blue), ⏳ researching (amber + progress bar), ✅ unlocked (green)
- Click → AcceptDialog confirmation with cost/duration/description
- Hover → tooltip popup showing description, prerequisites, and effect percentages
- Polls GameBridge every 2 s for live progress updates
- Emits `research_started` signal and `panel_close_requested` signal for parent scene integration

## Save/Load Compatibility

Research state is persisted in `GameState`:
- `UnlockedResearchIds: List<string>` — completed nodes
- `ActiveResearchId: string?` — in-progress node
- `ResearchProgress: int` — days elapsed

`SimulationEngine.Initialize()` restores all state via `ForceUnlock()` and `RestoreProgress()`.
