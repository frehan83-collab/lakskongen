### 1.2 Motif — "Nordic Aurora Fjord"

A flat-illustrated fjord scene built entirely from PIL drawing primitives:

- **Sky:** vertical gradient from deep fjord teal (`#0F3A4A`) through
  `#2A6B7C` to `#88C0D0` at the horizon.
- **Aurora:** soft blurred `#A3BE8C` ribbons across the upper sky.
- **Sun/moon:** pale `#ECEFF4` disc with a gaussian glow, plus a broken
  reflection column on the water.
- **Mountains:** three deterministic layered silhouettes
  (`#88C0D0` → `#2A6B7C` → `#0A4D68`) generated from fixed summed-sine ridges,
  with snow caps (`#ECEFF4`) on the distant range.
- **Water:** gradient `#5CA8B8` → `#2A6B7C` → `#0F3A4A`.
- **Salmon pens:** perspective ellipse cages with float rings, net mesh and
  radial spokes — the industry's iconic asset.
- **Salmon:** small stylized `#E8825C` fish.
- **Wordmark:** `LAKSKONGEN` in Inter Bold with letter tracking, an aurora-green
  accent rule, and the tagline "Build Your Salmon Empire" in Inter SemiBold.

Three motif variants are defined in the script (`aurora`, `dawn`,
`midnight_sun`); one cohesive variant is emitted per run.

**Palette:** `#0A4D68` (primary) · `#88C0D0` (secondary) · `#5E81AC` (accent) ·
`#ECEFF4` / `#2E3440` (bg/text) · water `#5CA8B8`/`#2A6B7C`/`#0F3A4A` ·
aurora `#A3BE8C`.

### 1.3 Regenerating

Requires Python 3.12 + Pillow only (no numpy / ImageMagick). Deterministic:
re-running produces byte-identical output.

```bash
python3 tools/gen_store_art.py                    # default 'aurora' set → capsules/
python3 tools/gen_store_art.py --variant dawn
python3 tools/gen_store_art.py --out /tmp/caps --no-preview
```

> ⚠️ **Honest note:** this art is procedurally code-generated, not hand-painted.
> It is intended as a coherent, on-brand placeholder that is far closer to a
> shippable identity than plain text-on-gradient. It should be reviewed by a
> human artist and can be replaced/refined before launch. Steam also composites
> `library_logo.png` over the hero, so the baked-in hero wordmark can be dropped
> by regenerating a text-free hero if desired.

- Use seasonal transitions (spring → summer → autumn → winter) as visual metaphor
