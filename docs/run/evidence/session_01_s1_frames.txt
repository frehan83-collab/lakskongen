## Mechanics shipped (see git for diffs)

1. **QA forcing bridge methods** (player-unreachable, deterministic):
   `StartQaScenario(scenarioId, seed)` (QA_SEED=20261012) · `SetQaPenLice` ·
   `SpawnQaBloom` · `ClearQaBlooms`; wired through `SimActions.gd`/`SimBridge.gd`;
   bridge contract test green.
2. **Collar tint rendering bug fixed**: the original `instance uniform` tint was
   proven set-at-node but never rendered (node probe `applied=(0.85,0.3,0.3,1.0)`
   vs pixel-sampled identical ring hue). Now: per-pen duplicated ShaderMaterial +
   regular uniform; the ring uses the sim tint as its primary color with a
   warning/critical glow (`pen_collar_shader.gdshader`).
3. **Harness hardening** (all kept): bounded `frame_post_draw` wait + window raise
   (no more occlusion hangs); in-`_shoot` UI force-hide with logged state; sim
   paused around forced captures (no lice decay); forced shots ordered before the
   underwater shot; `_configure_env` staging (proven framing path).
   The paused-then-resumed flow logs: `lice force: 0.600 via QA set (site
   po3_nord, lice_set)`, `bloom clear: removed N -> severity 0.00`,
   `bloom force: 0.00 -> 0.80 (bloom_spawned)`.
